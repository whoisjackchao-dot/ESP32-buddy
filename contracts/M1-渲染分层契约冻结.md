# M1 渲染分层契约冻结

> 状态：**M1 开工冻结（接口层已定；三个语义常量为提案值，用户已同意按提案实现并标注"待批准"）**
> 依据：本仓库《需求与决策基线》R20–R24、Q01–Q07；上游 `docs/protocol.md`、`firmware-rs/core/src/{display,look,canvas}.rs`
> 冻结日期：2026-10-16
> **本文件解除 M1「无渲染分层接口」的开工阻塞。**

## 1. 冻结范围

| 冻结 | 不冻结（各自里程碑前） |
| --- | --- |
| 三层职责与三方接口签名 | 具体绘制内容（除 IDLE/NORMAL 帧）（M2 前） |
| `pet_event_t` 事件枚举与语义 | 事件的具体线格式（仍走 S3P，M4 前） |
| 立绘/surface 数据格式 | 立绘在屏上的最终布局（M2/M4 前） |
| 声音一次性语义 | 番茄钟/任务卡字段（M3/M4 前） |

## 2. 分层与所有权

```
你的固件 (S3P/BLE) ─► pet_event_t ─► pet_state ─► pet_view_t ─► pet_render ─► pet_surface_t ─► pet_hal ─► 屏
```

- **只有 `pet_hal` 碰硬件**（SPI/LVGL/I²S/背光）。
- `pet_state` **不持有 hal 指针**，`now_ms` 由外部注入 → 可在 host 单测。
- `pet_render` 为纯函数，不 I/O。
- 三层之间只传**值**，不传硬件句柄。

## 3. 接口（唯一权威）

### 3.1 `pet_types.h`
```c
#pragma once
#include <stdbool.h>
#include <stdint.h>

/* 6 态，对应上游 display::State */
typedef enum {
    PET_STATE_IDLE = 0, PET_STATE_WORKING, PET_STATE_INPUT_REQUIRED,
    PET_STATE_DONE, PET_STATE_FAILED, PET_STATE_OFFLINE, PET_STATE_COUNT
} pet_state_t;

/* 立绘 4 关键帧，对应上游 look::Frame */
typedef enum {
    PET_FRAME_NORMAL = 0, PET_FRAME_EYES_CLOSED, PET_FRAME_HAPPY,
    PET_FRAME_SAD, PET_FRAME_COUNT
} pet_frame_t;

/* 一次性播报（上游 announcement） */
typedef enum {
    PET_SOUND_NONE = 0, PET_SOUND_INPUT, PET_SOUND_DONE, PET_SOUND_FAILED
} pet_sound_t;

#define PET_TITLE_MAX   64
#define PET_PROJECT_MAX 64

typedef struct {
    char        title[PET_TITLE_MAX];
    char        project[PET_PROJECT_MAX];
    pet_state_t state;
    int32_t     elapsed_s;
} pet_card_t;

typedef struct {
    pet_state_t state;
    pet_frame_t frame;
    bool        mirror;
    bool        gray;
    bool        has_card;
    pet_card_t  card;
} pet_view_t;
```

### 3.2 `pet_state.h`
```c
#pragma once
#include "pet_types.h"

typedef enum {
    PET_EV_AGENT_IDLE = 0, PET_EV_TASK_START, PET_EV_AGENT_INPUT_REQUIRED,
    PET_EV_TASK_DONE, PET_EV_TASK_ERROR, PET_EV_AGENT_BLOCKED,
    PET_EV_LINK_DOWN, PET_EV_LINK_UP, PET_EV_CARD, PET_EV_ANNOUNCEMENT
} pet_event_kind_t;

typedef struct {
    pet_event_kind_t kind;
    uint32_t         now_ms;
    const char      *title;
    const char      *project;
    pet_state_t      card_state;
    int32_t          elapsed_s;
} pet_event_t;

/* 不透明状态机句柄：只用结构体标签，避免与 pet_types.h 的枚举名
 * `pet_state_t` 冲突（2026-10-16 编译期发现，见「缺陷修订」）。 */
struct pet_state;

struct pet_state *pet_state_create(void);
void  pet_state_destroy(struct pet_state *s);
void  pet_state_apply(struct pet_state *s, const pet_event_t *ev);
void  pet_state_tick (struct pet_state *s, uint32_t now_ms);
void  pet_state_view(const struct pet_state *s, pet_view_t *out);
pet_sound_t pet_state_take_sound(struct pet_state *s);
```

### 3.3 `pet_render.h`
```c
#pragma once
#include "pet_types.h"

typedef struct {
    uint8_t *pixels;   /* RGB565 little-endian, row-major */
    int      width, height, stride;   /* stride = 每行字节数 */
} pet_surface_t;

typedef struct pet_look pet_look_t;
pet_look_t *pet_look_parse(const uint8_t *bytes, size_t len);
void        pet_look_free (pet_look_t *look);

void pet_render_pet(const pet_view_t *v, const pet_look_t *look,
                    pet_surface_t *surface, int x, int y);
void pet_render_scene(const pet_view_t *v, const pet_look_t *look,
                      pet_surface_t *surface);
```

### 3.4 `pet_hal.h`

## 4. 数据格式

| 项 | 冻结值 | 依据 |
| --- | --- | --- |
| 立绘 | 48×64，4bpp，RGB565 调色板（entry 0 = 透明），4 帧 | 上游 `look.rs`（源码级） |
| 立绘字节序 | magic `"LOOK"` + `u8 w,h,frames,0` + `u16[16]` 调色板 + 帧数据（row-major，左像素在低半字节，little-endian） | 上游 `look.rs` |
| surface | RGB565，**little-endian**，row-major，`stride` 显式 | 本项目拟定 |
| 屏幕上放大 | 立绘按 **2×** 绘制（48×64 → 96×128） | 上游 `look::SCALE=2` |

## 5. 参数表（含"待批准"标注）

| 符号 | 值 | 单位 | 依据 | 状态 |
| --- | --- | --- | --- | --- |
| `PET_DONE_DWELL_MS` | **5000** | ms | 上游 `protocol.md`："after 5 seconds it goes back to the cards" | ⏳ **待批准**（按提案实现） |
| `PET_LINK_TIMEOUT_MS` | **15000** | ms | 上游 README："15 秒收不到 Mac 的消息就判定链路断开" | ⏳ **待批准** |
| `PET_HEARTBEAT_MS` | **10000** | ms | 上游 `protocol.md`：心跳 10s | ⏳ **待批准** |
| `PET_ORIGIN_X` | **19** | px | 提案：(135−48×2)/2 居中 | ⏳ **待批准** |
| `PET_ORIGIN_Y` | **56** | px | 提案：(240−64×2)/2 居中 | ⏳ **待批准** |

> **常量批准前置**：上表五个符号在 M2 开工前必须有**批准值**。`PET_LINK_TIMEOUT_MS`/`PET_HEARTBEAT_MS` 与既有 S3P 的 10s/15s 规则一致，可直接沿用；`PET_DONE_DWELL_MS` 与原点需 M2 前定稿。

## 6. 状态机语义（M1 只冻结枚举；转移规则 M2 前补）

| 事件 | 目标态 | 播报 |
| --- | --- | --- |
| `PET_EV_AGENT_IDLE` | IDLE | — |
| `PET_EV_TASK_START` | WORKING | — |
| `PET_EV_AGENT_INPUT_REQUIRED` | INPUT_REQUIRED | `PET_SOUND_INPUT`（一次） |
| `PET_EV_TASK_DONE` | DONE（驻留 `PET_DONE_DWELL_MS` 后回 IDLE 或卡栈） | `PET_SOUND_DONE`（一次） |
| `PET_EV_TASK_ERROR` / `PET_EV_AGENT_BLOCKED` | FAILED | `PET_SOUND_FAILED`（一次） |
| `PET_EV_LINK_DOWN` | OFFLINE（`gray=true`） | — |
| `PET_EV_LINK_UP` | 回到由最近事件决定的态 | — |

**`done` 边沿（B01，M2 前冻结细则）**：当无显式 `PET_EV_TASK_DONE` 时，`WORKING/INPUT_REQUIRED → IDLE` 的下降沿可合成一次 DONE；须对 `retry` 抖动去抖。**不承诺**零误报/零漏报。

## 10. 增量修订：立绘 4→6 帧（2026-10-17）

> 追加记录，不改写上文。原 §3.1 / §4 中"立绘 4 帧"的表述自本节起以 6 帧为准。

| 项 | 原冻结值 | 现值 |
| --- | --- | --- |
| `pet_frame_t` | `NORMAL=0, EYES_CLOSED=1, HAPPY=2, SAD=3` | **追加** `PET_FRAME_WORKING=4`、`PET_FRAME_INPUT=5`，`PET_FRAME_COUNT=6`；0–3 编号不变 |
| LOOK 包 | magic/w/h/**frames=4**/0 + 调色板 + 4 帧数据（6184 B） | 格式不变，仅 frames 字节 4→6（**9256 B** = 40 + 6×1536） |
| 状态→帧映射 | WORKING/INPUT_REQUIRED 无专属帧（用 NORMAL + 头顶标记区分） | IDLE→NORMAL(0)（眨眼/小动作仍复用帧 1），WORKING→WORKING(4)，INPUT_REQUIRED→INPUT(5)，DONE→HAPPY(2)，FAILED→SAD(3)，OFFLINE→EYES_CLOSED(1) |
| 解析校验 | `pet_look_parse` 拒绝错误 magic/w/h/frames/长度 | 不变（按 frames=6 校验） |
| 头顶标记 | WORKING=">"、INPUT="!?"（§8.2 / M2 §8） | 不变，继续叠加 |

- 美术为**原创**毛绒吉祥物（风格受 Meta Muse 吉祥物方向启发，不复制其素材/造型/数据；生成器 `tools/make-look.py` 净室自绘）。
- 已知取舍：OFFLINE 与 idle 眨眼/打盹共用帧 1（EYES_CLOSED），帧内不画 "Z z"，否则 1 Hz 眨眼时会闪烁；OFFLINE 靠闭眼睡姿 + 灰化区分。专属睡姿需第 7 帧，超出本次范围。
- 回填测试：`test_pet_render`（包尺寸/帧数断言 + 6 帧两两不同）、`test_pet_state`（6 态→6 帧映射）、`tools/sim`（6 帧单图）。证据：`evidence/M1/2026-10-17-立绘6态升级-D.md`。
