## 2. 约束（必须先看）

- 屏 **135×240 竖屏**，宠物 2× 后 **96×128**，**一屏放不下**"宠物 + 3 卡 + 统计 + 圆环"同时展示。
- 上游 320×240 的坐标**不可照抄**（`PET_ORIGIN_*` 已在 M1 契约标为提案）。
- 中文字体是已知难点（旧项目同样遗留"中文字体待实机验证"）——**不承诺**首版就显示中文；可先用 ASCII/图标。

## 5. 冻结（2026-10-16，M3 版式 + 任务卡增量）

> 只冻结本节点要用的部分；多卡栈（≤3）、圆环区（M7）、中文字形仍待产出。

### 5.1 竖屏分区（135×240）

| 区 | 矩形 | 说明 |
| --- | --- | --- |
| 宠物区 | 原点 **(19, 8)**，尺寸 **96×128** | 2× 立绘，水平居中 |
| 卡片区 | `x=4, y=146, w=127, h=58` | M3 只画 1 张 |
| 底部保留 | `y 206..240` | 留给统计/圆环（M7） |

### 5.2 卡片内容（1 张）

| 行 | 内容 | 缺省 |
| --- | --- | --- |
| 1 | 任务名（`card.title`） | `"[NO TASK]"` |
| 2 | 项目名（`card.project`） | 留空 |
| 3 | 驻留时长（`card.elapsed_s` → `"12M"` / `"45S"`） | `"-"` |

- **左侧 3px 状态色条**：`WORKING`/`INPUT_REQUIRED`=`0xFD20`，`DONE`=`0x07E0`，`FAILED`=`0xF800`，其余=`0x8410`。
- **Agent 前缀**（`OC:` 等）**本节点不做**，随事件模型（M4）进入。

### 5.3 字体与截断

| 项 | 值 |
| --- | --- |
| 字体 | **8×8 点阵**（`font8x8_basic.h`，公有领域；来源已在 NOTICE 登记），**scale=1** |
| 每行最大字符数 | **14**（`(127-8)/8`） |
| 截断 | 超过 14 字符**直接截断**（不加省略号） |
| 字符宽度 | 8px；行高 16px |

### 5.4 颜色

| 符号 | 值 | 用途 |
| --- | --- | --- |
| `CARD_BG` | `0x0841` | 卡背景 |
| `CARD_BORDER` | `0x4208` | 边框 |
| `CARD_TITLE` | `0xFFFF` | 任务名 |
| `CARD_PROJECT` | `0x8410` | 项目名 |
| `CARD_ELAPSED` | `0xFFFF` | 时长 |

### 5.5 参数（提案值，**待批准**）

| 符号 | 值 |
| --- | --- |
| `CARD_X/Y/W/H` | 4 / 146 / 127 / 58 |
| `CARD_TEXT_MAX` | 14 |

## 6. 明确不做

- 不做多卡栈版式（M8）。
- 不做上游横屏坐标的等比缩放（会糊）。
- 不承诺中文字形完整。
- 不做 Agent 前缀（M4）。
