# contracts/ —— 契约冻结与清单

本目录放两类产物，**按成熟度演进**：

| 形态 | 何时用 | 文件特征 |
| --- | --- | --- |
| **清单**（未冻结） | 还没到冻结时点 | 列 `# \| 冻结项 \| 需要产出的值 \| 关联测试 \| 状态`；结果**未定**是合法且有用的 |
| **冻结文档**（取值已定） | 该节点开工前 | 给出**唯一确定取值**，声明解除了哪些开工阻塞 |

状态符号：`✅ 已批准` / `✅ 已冻结` / `🟡 部分冻结（只冻结该增量需要的取值，其余仍待冻结）` / `⏳ 清单就绪，取值待冻结` / `⏳ 未开始`。
