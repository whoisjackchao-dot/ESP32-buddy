# M9 验收测量契约（冻结 2026-10-23）

> **目的**：把 `G1–G7` 的"什么叫达标"变成**可复核的观测定义**。任何"上屏 / 失联 / 播报"都必须写明起点与终点。
> **铁律**：失败、超时、异常**全部留在分母**；分组不得合并；不得事后剔除或改口径。
> 关联：基线 §6（G1–G7 已批准 2026-10-23）、`05-acceptance`、`evidence.md`。

## 1. 通用规则

- 每次尝试记录：`开始时刻 / 结束时刻 / 结果(pass|fail|timeout) / 证据行`。
- 报告必须含：**总尝试、达标、失败、超时**；达标率的分母是总尝试。
- 时钟：host 用 `time.monotonic()`；设备日志带 `esp_timer` µs（**仅设备内自证，不参与跨机时延**）。
- 跨机时延一律用 **host 发送完成 → host 收到对应日志行**（含 USB 链路，诚实口径；不量中间环节）。

## 2. 设备侧可观测性（新增，**D 类**；需固件刷写）

| 日志 | 触发时机 | 格式（**ASCII**） | 用途 |
| --- | --- | --- | --- |
| `rf` | 渲染视图的**（状态, 卡数, 顶卡标题）变化**时，在**该帧绘制前**记录一次 | `rf t=<us> st=<n> n=<k> top=<title≤8>` | G3 / G6 上屏 |
| `off` | 链路 **在线→离线** 转变 | `off t=<us>` | G4 |
| `on` | 链路 **离线→在线** 转变 | `on t=<us>` | G4 对照 |
| `voice` | **实际开始播放**某音效 | `voice id=<0..3> t=<us>` | G7 |

- 频率：`rf` 仅变化时；其余仅事件时；**不得污染** `st:` 1s 心跳。
- 输出走 USB-Serial-JTAG 控制台；host 用 pyserial 读 `COM5`。

## 3. 逐门槛测量定义

### G1 六态目视（人工）
- **6 态 ×（进入 10 + 退出 10）= 120 次**；harness 发事件并提示操作者目视判定。
- PASS：120/120 目视正确；逐次记录。

### G2 番茄钟（人工 + 重启持久化）
- 完成 / 暂停 / 放弃 **各 10 次 = 30 组**（真机按键）；逐组记录。
- NVS：每轮记 `done/focus_s`，**重启 10 次**，PASS 10/10 保留。

### G3 任务卡更新（自动）
- **20 次**不同卡片更新（title/elapsed 变化）；每次记 `send → rf` 时延。
- PASS：**20/20 ≤ 1000 ms**；超时算失败并留分母。

### G4 失联（自动）
- **20 次**：停心跳（停 daemon）→ 等 `off` 行；记 `停发 → off` 时延。
- PASS：**≥19/20 落在 15–17 s**；>20 s 记 `timeout`（失败）。

### G5 稳定性（自动 + 人工巡检）
- **插电连续 120 min**；每 10 min 记 `st:` 心跳；结束检查：无重启（boot 次数）、无看门狗、fps 稳定。
- PASS：120 min 无死机/无阻塞；失败如实记录（不得以"没崩溃"替代诊断）。

### G6 事件入口（自动）
- **20 次**不同事件，任意本机脚本 POST → 设备 1 s 内显示；口径同 G3。
- PASS：**20/20 ≤ 1000 ms**。

### G7 语音（自动 + 耳听抽检）
- **20 次**：循环 `INPUT/DONE/FAILED`（约 7/7/6）；每次先回 `WORKING` 再触发。
- **对照组**：`WORKING/IDLE/heartbeat` 各 5 次（应静默）。
- PASS：20/20 恰好 **1 条正确 id** 的 `voice`；对照组 **0 条**；无重复、无误播。

## 4. harness

- `tools/acceptance.py`（**Windows 侧** python，pyserial；WSL 经 interop 调用）
- 子命令：`g3` / `g4` / `g6` / `g7`（自动）；`g1` / `g2` / `g5`（人工引导 + 结果录入）
- 输出：`evidence/M9/<date>-<gate>.{json,md}`（**分母完整、逐次记录**）

## 5. 明确不承诺

- 不承诺跨设备时钟同步；时延**含 USB 链路**。
- 不承诺 120 min 之外的长期稳定性。
- `G5` 的"无阻塞"以 **1 s 心跳连续 + 无重启**为判据，不做内存/任务级剖析。
