## 6. 冻结（2026-10-16，M7 增量 1：**设备侧番茄钟逻辑**）

> 本增量只冻结**纯逻辑**（计时状态机 + 当日统计），host 可测（`tests/test_pet_pomo.c`）。
> **不**读 GPIO（按键属 M6）；**不**画圆环（7.5，增量 2）；**不**做 NVS 落盘（7.7，增量 2）；**不**取"今天"（7.9，外部输入）。
> 模块：`firmware/components/pet/pet_pomo.c` + `include/pet_pomo.h`。

### 6.1 状态机（`pet_pomo_phase_t`）

`IDLE` / `FOCUS` / `FOCUS_PAUSED` / `BREAK` / `BREAK_PAUSED` / `FOCUS_DONE` / `BREAK_DONE`。

命令 `pet_pomo_cmd_t`：`PET_POMO_CMD_SHORT`（KEY1 短按：开始/暂停/继续/推进）、`PET_POMO_CMD_LONG`（KEY1 长按：放弃）。

| 当前 | `SHORT` | `LONG` |
| --- | --- | --- |
| `IDLE` | → `FOCUS` 启动 | 无变化 |
| `FOCUS` | → `FOCUS_PAUSED` | → `IDLE`（放弃，**不计完成**） |
| `FOCUS_PAUSED` | → `FOCUS` 继续 | → `IDLE`（放弃） |
| `FOCUS_DONE` | → `BREAK` 启动（**不自动**） | → `IDLE` |
| `BREAK` | → `BREAK_PAUSED` | → `IDLE` |
| `BREAK_PAUSED` | → `BREAK` 继续 | → `IDLE` |
| `BREAK_DONE` | → `IDLE` | → `IDLE` |

### 6.2 计时

- `pet_pomo_tick(p, now_ms)`：仅 `FOCUS`/`BREAK` 推进 `elapsed_ms += now_ms - since_ms` 并更新 `since_ms`；暂停/完成/空闲不推进。
- 相位进入（启动/继续/推进）时把 `since_ms = now_ms`。
- `FOCUS` 的 `elapsed_ms >= POMO_FOCUS_MS` → `FOCUS_DONE`，置 `alarm=true`，**统计 `done_count++`、`focus_seconds += POMO_FOCUS_MS/1000`（=1500）**。
- `BREAK` 的 `elapsed_ms >= POMO_BREAK_MS` → `BREAK_DONE`，置 `alarm=true`；**不计入统计**。
- **边界**：`elapsed_ms == total` 即视为到点（`>=`）。

### 6.3 当日统计

- 字段：`done_count`（完成专注段数）、`focus_seconds`（累计专注秒）。
- `pet_pomo_set_day(p, day)`：`day`（外部提供的天数序号）与上次不同（或首次）→ **统计清零**并记下 `day`；相同 → 不动。
- **不持久化**（增量 2）；本增量统计仅在 RAM。

### 6.4 API（`pet_pomo.h`，值语义、无 malloc）

```c
typedef struct {
    pet_pomo_phase_t phase;
    uint32_t since_ms;        /* 上次推进/相位进入的时刻 */
    uint32_t elapsed_ms;      /* 本段已累计 */
    uint32_t total_ms;        /* 本段总时长 */
    uint32_t done_count;      /* 当日完成专注段数 */
    uint32_t focus_seconds;   /* 当日累计专注秒 */
    bool     alarm;           /* 待响铃（取走即清） */
    bool     has_day;
    int32_t  day;
} pet_pomo_t;

typedef struct {
    pet_pomo_phase_t phase;
    uint32_t remaining_ms;    /* total_ms - elapsed_ms，下限 0 */
    uint32_t total_ms;
    uint32_t done_count;
    uint32_t focus_seconds;
    bool     alarm;
} pet_pomo_view_t;

void pet_pomo_init(pet_pomo_t *p, uint32_t now_ms);
void pet_pomo_command(pet_pomo_t *p, pet_pomo_cmd_t cmd, uint32_t now_ms);
void pet_pomo_tick(pet_pomo_t *p, uint32_t now_ms);
void pet_pomo_set_day(pet_pomo_t *p, int32_t day);
void pet_pomo_view_get(const pet_pomo_t *p, pet_pomo_view_t *out);
bool pet_pomo_take_alarm(pet_pomo_t *p);   /* 返回待响铃并清零 */
```

### 7.1 圆环几何（提案，见 §1 7.5；135×240）

| 项 | 值 |
| --- | --- |
| 位置 | **复用宠物区**：环心 `(67, 72)`（= 19+48, 8+64） |
| 外半径 `R` / 环厚 `T` | `48` / `6` |

### 7.3 统计持久化（编解码，**host 可测**）

- 固定 blob（`PET_POMO_STATS_LEN = 16`），**little-endian**：

| 偏移 | 字段 | 类型 |
| --- | --- | --- |
| 0 | magic `"PMC1"` | 4 字节 |
| 4 | `day` | `int32` |
| 8 | `done_count` | `uint32` |
| 12 | `focus_seconds` | `uint32` |

- `size_t pet_pomo_encode_stats(uint8_t *buf, size_t cap, const pet_pomo_t *p);`（`cap<16` → 0）
- `bool pet_pomo_decode_stats(const uint8_t *buf, size_t len, pet_pomo_t *p);`（magic/长度不符 → `false`，**不改 `p`**）

### 7.4 引擎接入

- `pet_engine_set_mode(mode)`；`mode ∈ {PET_MODE_DUTY, PET_MODE_POMO}`，**默认 DUTY**。
- `POMO`：`pet_pomo_tick(now)` + `pet_render_pomo`；`DUTY`：现状（宠物 + 卡）。
- 统计落盘走 NVS：`pet_pomo_nvs_load/save`（设备侧），在模式切换时存/取。
- **模式切换的调用方 = M6（KEY2）**；本增量不实现按键。
