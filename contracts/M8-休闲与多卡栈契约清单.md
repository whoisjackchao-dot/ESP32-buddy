## 6. 冻结（2026-10-17，M8 增量 1：休闲状态机 · host 可测）

> **状态：✅ 增量 1 已实现（2026-10-17）** —— `pet_leisure` 纯逻辑；C **470/0**（LEI 50 checks）。设备侧接入（小剧美术 / 背光）属**增量 1b**；NTP/夜间时间源属**增量 2**。

> **时间与"是否夜间"由外部注入**（`tick(now_ms, agent_active, hour24)`）；**NTP/夜间来源属增量 2**（`Q17=A` 仅授时）。
> 本增量只做**状态机 + 小剧调度**（纯逻辑）；小剧美术/背光属设备侧（增量 1b）。

### 6.1 阶段

`DUTY`（值班）→ **空闲 5 min** → `BORED` → **累计 30 min** → `SLEEPY` → **累计 90 min 且夜间** → `LIGHTS_OUT`。

- **唤醒**：`agent_active`（有事件）、按键、断链 → **立即回 `DUTY`** 并**重置**空闲计时。
- 夜间窗口 `23:00–07:00`（`hour24` 注入；`LIGHTS_OUT` 仅在夜间）。

### 6.2 小剧

- `BORED`：每 **20–40 s** 一段；**首段延迟 3 s**。
- `SLEEPY`：每 **120–300 s**。
- 剧目 id `0..6`（巡逻/踢球/看书/数星星/躲猫猫/被自己吓醒/梦话），**轮换**（`(上一段+1)%7`）。
- 间隔用**确定性 PRNG**（seed 由 `init` 注入，便于测试）。

### 6.3 API

```c
typedef enum { PET_LEI_DUTY = 0, PET_LEI_BORED, PET_LEI_SLEEPY, PET_LEI_LIGHTS_OUT } pet_leisure_phase_t;

typedef struct { /* 内部字段 */ } pet_leisure_t;

void pet_leisure_init(pet_leisure_t *l, uint32_t now_ms, uint32_t seed);
void pet_leisure_tick(pet_leisure_t *l, uint32_t now_ms, bool agent_active, int hour24);

pet_leisure_phase_t pet_leisure_phase(const pet_leisure_t *l);
int  pet_leisure_skit(const pet_leisure_t *l);       /* 当前剧目 0..6；-1=无 */
bool pet_leisure_lights_out(const pet_leisure_t *l); /* 关背光 */
```

## 7. 冻结（2026-10-17，M8 增量 1b：小剧渲染 + 背光 + 引擎接入）

> **状态：✅ 增量 1b 已实现并真机通过（2026-10-17，demo 阈值）** —— 7 种小剧可见、25 s（demo）背光关闭、按键唤醒恢复背光（用户"1-3 都正常了"）。C **485/0**。
> **未**验证真实 5/30/90 分钟（逻辑 T 测）；**NTP 夜间时间源属增量 2**（当前 `hour24=-1` → 不熄屏）。
> **注意**：休闲需设备**在线**（心跳）；OFFLINE 按契约回值班会清零计时。

> 在 §6 状态机之上：把 7 个剧目**画出来**、`LIGHTS_OUT` **关背光**、并在**值班模式**下运行休闲。
> 仍然**只有头像**（无身体/四肢/耳朵）：小剧 = **头像位移 + 小道具**。

### 7.1 小剧渲染 API

```c
void pet_render_skit(pet_surface_t *s, const pet_look_t *look,
                     const pet_view_t *v, int skit_id, uint32_t t_ms);
```

- 整屏底色 + 头像（`pet_render_pet`）按下列**位移/道具**绘制；`t_ms` 为**小剧起始后**的毫秒。
- 位移以 2 s 为周期（`phase = t_ms % 2000`）：

| id | 剧目 | 表现（提案） |
| --- | --- | --- |
| 0 | 巡逻 | 头像 **x = ±6** 来回（`sin`） |
| 1 | 踢球 | 头像 **y 弹跳 ±3**；右下画一颗 **8×8 小球**（沿弧线） |
| 2 | 看书 | 头像略低（+2）；下方画一本 **小书**（16×8 矩形 + 两条书页线） |
| 3 | 数星星 | 头像 **上抬 −2**；上方 3 颗**星光**闪烁（交替显隐） |
| 4 | 躲猫猫 | 头像 **上下躲**（y 0→+10→0）；躲下时用闭眼帧 |
| 5 | 被吓醒 | 头像 **急跳 −6→0**；用**睁大眼**帧（`PET_FRAME_INPUT`） |
| 6 | 梦话 | 头像静止；闭眼帧 + 嘴部小开合（2 帧交替） |

- 道具颜色沿用调色板（`YELLOW`/`WHITE`/`GRAY` 等硬编码 RGB565 常量，与头顶标记同法）。
- 越界裁剪与 `pet_render_pet` 一致。

### 7.2 引擎接入

- **值班模式**下每帧：`pet_leisure_tick(now, agent_active, hour24)`。
  - `agent_active` = 当前 `pet_state` 为 `WORKING` / `INPUT_REQUIRED`（有 Agent 在干活）；其余为 false。
  - `hour24` 由**外部提供**（增量 2 前固定 `-1` = 未知 → **不熄屏**，并在日志标注"时间未知"）。
- `BORED`/`SLEEPY` 且 `pet_leisure_skit() >= 0` → 用 `pet_render_skit(...)` 画小剧；否则画值班场景。
- `LIGHTS_OUT` → `hal->set_backlight(false)`；任何唤醒（`agent_active`/按键/断链）→ `set_backlight(true)`。
- 番茄钟模式**不跑休闲**（保持番茄钟视图）。

### 7.3 明确不做（增量 1b）

- 不做 NTP/真实夜间时间（增量 2；`hour24=-1` 时**不熄屏**）；不做小剧的复杂逐帧美术；不做多卡。

## 8. 冻结（2026-10-17，M8 增量 2：多卡栈 ≤3 · **按到达时间，新在上**）

> 线格式在本节扩展 `tasks[]`（`M4 §6.1` 的 M8 扩展）。

### 8.1 线格式扩展

- 新增**可选**键 `tasks`：数组（取前 **3** 项），每项 `{title, project, elapsed_s, status}`；`status ∈ working/input_required/done/failed`（缺省 `working`，未知值按 `working`）。
- 类型不符的项**忽略**；`tasks` 非数组 → 忽略该键（不影响单卡字段）。
- 顶层单卡字段（`title/project/elapsed_s`）仍兼容。

### 8.2 栈（`pet_state`）

- `pet_card_t cards[3]; int card_count;`
- 事件带卡：以 **title** 识别——已存在 → **更新并移到顶部**；否则**入栈顶**；>3 → 丢**最旧（底部）**。
- `pet_state_set_card(s, card)` 语义改为"**入栈/更新**"（空 title 的卡忽略）。

### 8.3 视图

- `pet_view_t` 增 `int card_count; pet_card_t cards[3];`；保留 `card`/`has_card`（= 顶部卡，兼容旧代码与测试）。

### 8.4 渲染（3 卡紧凑版式）

- `card_count == 0` → 无卡；`== 1` → **沿用现有大卡**（用户已调过字号/颜色）。
- `>= 2` → **紧凑行**：卡区 `x=4..131, y=150..236`；每行 **28 px**（顶部卡在最上）；每行：
  - 左侧 3px 状态色条（沿用 `state_accent`）；
  - 标题（1×，最多 14 字符）；
  - 第二行 `project · elapsed`（1×，最多 14 字符，灰色）。
- 3 行占 84 px（150..234），不越界。

### 8.5 明确不做（本增量）

- 不做卡滚动/超过 3 张；不做多 Agent 前缀（`8.13` 属多 Agent 增量）；不做卡点击。

## 4. 明确不做

- 不做超过 3 张卡。
- 不做除 OpenCode 外的 Agent（除非各自 spike 通过）。
- 不做 WiFi 中继（Relay）——除非 `Q17` 明确要求。
- 不做小剧的美术定制（先复用上游立绘的灰度/姿态）。
