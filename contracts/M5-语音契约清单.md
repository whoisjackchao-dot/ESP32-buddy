## 5. 冻结（2026-10-16，M5 增量 1：语音逻辑与资产格式）

> 触发规则**已在 M2 契约 §7/§8 冻结**（`INPUT`/`DONE`/`FAILED` 各播一次；`WORKING`/`IDLE`/`OFFLINE` 静默；去重靠 `pet_state_take_sound` 取走即清）。
> 本增量冻结**资产格式、映射与静音**；**设备播放属增量 2**。

### 5.1 资产格式

| 项 | 值 |
| --- | --- |
| 编码 | **16-bit signed，little-endian，单声道** |
| 采样率 | **16 kHz**（与既有 I2S/ES8311 一致） |
| 文件 | `assets/input.pcm` / `assets/done.pcm` / `assets/failed.pcm` |
| 装载 | 组件 `EMBED_FILES`（与 `robot.look` 同法） |
| 时长范围 | 每段 **0.1–3.0 s**（超出判非法） |

### 5.2 映射与静音

| 规则 | 说明 |
| --- | --- |
| 映射 | `PET_SOUND_INPUT/DONE/FAILED` → 一一对应；`PET_SOUND_NONE` → 无 |
| `pet_voice_should_play(sound, muted)` | `NONE` → `false`；`muted` → `false`；其余 → `true` |
| 静音开关 | `pet_voice_set_muted(bool)`；**不持久化**（重启恢复有声，与上游一致） |

### 5.3 占位资产

- 本增量先用 **合成音**（自绘、无许可问题）作为占位，**不是语音**；
- **真实语音资产来源仍待批准**（见 §4 的三选一）。

### 5.4 增量 2（未开工）

- 设备侧播放：I2S TX + ES8311，复用同作者既有 StickS3 项目（MIT）的实现；
- **需引入 managed 组件 `espressif/es8311`**（本机尚无）→ 新机器构建需要组件仓库（或改为 vendored）。

## 6. 明确不做

- 不做语音输入/麦克风（硬件有 MEMS 麦克风，但本阶段不做）。
- 不做 TTS 供应商接入。
- 不在 `WORKING` 时播报。
- 不做静音持久化。
