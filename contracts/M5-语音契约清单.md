## 5. 冻结（2026-10-16，M5 增量 1：语音逻辑与资产格式）

> 触发规则**已在 M2 契约 §7/§8 冻结**（`INPUT`/`DONE`/`FAILED` 各播一次；`WORKING`/`IDLE`/`OFFLINE` 静默；去重靠 `pet_state_take_sound` 取走即清）。
> 本增量冻结**资产格式、映射与静音**；**设备播放属增量 2**。

### 5.1 资产格式

| 项 | 值 |
| --- | --- |
| 编码 | **16-bit signed，little-endian，单声道** |
| 采样率 | **16 kHz**（与既有 I2S/ES8311 一致） |
| 文件 | `assets/input.pcm` / `assets/done.pcm` / `assets/failed.pcm` |
| 装载 | 组件 `EMBED_FILES`（与 `robot.look` 同法） |
| 时长范围 | 每段 **0.1–3.0 s**（超出判非法） |

### 5.2 映射与静音

| 规则 | 说明 |
| --- | --- |
| 映射 | `PET_SOUND_INPUT/DONE/FAILED` → 一一对应；`PET_SOUND_NONE` → 无 |
| `pet_voice_should_play(sound, muted)` | `NONE` → `false`；`muted` → `false`；其余 → `true` |
| 静音开关 | `pet_voice_set_muted(bool)`；**不持久化**（重启恢复有声，与上游一致） |

### 5.3 资产来源（**已定：B 自合成**，2026-10-16 用户决定）

| 项 | 值 |
| --- | --- |
| 方式 | **自合成**（无第三方 API Key） |
| 工具 | `tools/voice-tts.sh`（`edge-tts` + `ffmpeg`，免费、无需 Key） |
| 音色 | **`zh-CN-XiaoyiNeural`**（女声，活泼；可换 `zh-CN-XiaoshuangNeural` 童声） |
| 文案 | `需要你确认一下` / `都做完啦` / `出错啦` |
| 离线占位 | `tools/make-voice.py` 保留：无网络时生成合成音占位 |

> **许可提示**：语音由微软 Edge 朗读服务合成（`edge-tts` 本身为 MIT）。**再分发该音频前需自行确认其服务条款**；见 NOTICE §3。

### 5.4 增量 2（**已实现**，2026-10-16）

- 设备侧播放：`pet_audio.c`（I2S TX + ES8311），**异步队列 + 独立任务** → **不阻塞动画节拍**（满足"不阻塞主循环"）。
- 组件引入方式：**B vendored**（用户 2026-10-16 决定）→ `firmware/components/es8311/`；
  **Apache-2.0**，来自 `espressif/esp-bsp`（`1.0.0~1`，commit `4dabefca`），**自包含、离线可构建**。
- 复用同作者既有实现（MIT）的**已验证参数**：16 kHz / 16-bit / **STEREO 槽位**（MONO 会 2 倍拉伸）/ MCLK×256 / I2S_NUM_0 / MCLK=18 BCLK=17 WS=15 DOUT=14。
- 资产以 `EMBED_FILES` 嵌入（app 由 281 KB 增至 **496 KB**，1 MB 分区余 53%）。
- 播放流程含 **功放使能 → 解除静音 → 写入 → 静音尾 → 静音 → 关功放**（防残留长鸣）。
- **未实机验证**（H 类待设备）。
