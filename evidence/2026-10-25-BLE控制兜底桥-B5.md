# B5：BLE 控制兜底桥（主机侧）

- 日期：2026-10-25
- 组件：`host/ble_bridge.py`（Windows Python 3.12 + winrt）+ `host/pet_supervisor.py` 第 3 个子进程
- 链路：设备 BLE GATT `0xFFE0`/TX `0xFFE2` notify → **转发到本机 `:8767`**（file_to_serial 的 ControlServer）→ 与 USB/WiFi **共用同一消费者与 500ms 去重**
- 原理：设备 `pet_engine_send_line` 同时走 USB+WiFi+BLE，主机侧三路到一个消费者，只执行一次

## 真机验证
| 项 | 结果 |
| --- | --- |
| 守护 3 子进程 | ✅ oc_poll / file_to_serial / **ble_bridge** 全部 running |

| 控制行转发 | ✅ 菜单 BACK: WINDOW → `ble->8767 ok=True {"v":1,"cmd":"back_window"}` → 窗口回前台 |
| 断线重连 | ✅ 观察到 WinError → retry → 重新订阅成功 |

## 策略（B4 结论）
- 设备：BLE **广告常开**（开销小），连接态由主机控制
- 主机：BLE 桥常连（保证控制可靠）；WiFi+BLE 同连时射频 50/50 → **ASR 上传可能约 2× 变慢**（可接受；如介意可停用第 3 子进程）
