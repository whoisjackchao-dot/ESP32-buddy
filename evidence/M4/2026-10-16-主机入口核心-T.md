```

```

| 用例 | 断言要点 |
| --- | --- |
| `E2E-02` | 简式 `{"version":1,"event":"task.done","title":"Hello"}` → `OK`/200，线恰为 `{"version":1,"event":"task.done","title":"Hello"}\n`；富式 `tasks[0]` 的 title/project/elapsed_s 优先、顶层陈旧字段被忽略；`device.heartbeat` 无卡字段 → 线仅 version+event；title 超 100 字符截断到 **63**；`stats` 被忽略且不进线；**loopback 集成**：`make_server(port=0, sink=…)` + 线程运行，`urllib` POST 合法事件 → 200 且 sink 收到该行 |
| `E2E-03` | GET → `METHOD`/405；`/bad` → `NOT_FOUND`/404；content-type `text/plain` 与缺失 → `CONTENT_TYPE`/415；body 513 字节 → `TOO_LONG`/413；非 JSON 与顶层 `[]` → `JSON`/400；version 缺失或 =2 → `VERSION`/400；event 缺失或 =123 → `EVENT`/400；未知事件 → `UNKNOWN_EVENT`/400；`title=7`、`elapsed_s=-1`、`elapsed_s=true`、`tasks` 非 list、`tasks[0]` 非 dict → `TYPE`/400；**集成**：POST 非法事件 → 400 且 **sink 未再被调用**（不广播）；GET → 405 |
| `SEC-01` | `srv.server_address[0] == "127.0.0.1"`（仅 loopback 绑定；`make_server` 默认 host=`127.0.0.1`，无 0.0.0.0 路径） |

另做一次**人工冒烟**（非用例）：`PET_EVENT_PORT=8899 python3` 起 `make_server()`（无 port 参数）→ 绑定 8899（环境变量覆盖生效）；带 `Content-Type: application/json; charset=utf-8` POST `title=中文` → 200，默认 sink（stdout）原样打印 `{"version":1,"event":"task.start","title":"中文","elapsed_s":75}`（UTF-8 直传，非 `\uXXXX`）。

实现取向的两处**契约留白**（选 §8 一致读法，已在代码注释标注）：
- `tasks` 为**空数组**时视为"无 `tasks[0]`"→ 回退顶层字段（`tasks` 非空但 `tasks[0]` 非 dict 仍 `TYPE`）。
- 产出线用 `json.dumps(..., ensure_ascii=False)`：§6.1 声明 UTF-8 且只支持 `\" \\ \/ \n \t` 转义，`\uXXXX` 设备侧不认识，故非 ASCII 原样直传（冒烟已验证）。

## 4. 残余风险

| 风险 | 说明 |
| --- | --- |
| **传输未接** | sink 默认仅打印 stdout；真实 BLE/串口未实装（增量 2b，契约 §8.6 明确不做）→ M4 **不算完成** |
| **OpenCode 映射未做** | R11 仍 `NOT_RUN`：无 OpenCode 真源接入，事件仅能由任意本机脚本手发 |
| token 未定 | 鉴权目前**只有 loopback 绑定**（4.4）；同机任意进程仍可 POST，是否加 token 待定 |
| 服务器健壮性边界 | `Content-Length` 缺失按空 body → `JSON`/400；`Content-Length` 超限时**不读 body** 直接 413（防大包）——这两条为服务器分支，仅核心侧 TOO_LONG/JSON 有单测，服务器分支靠集成路径间接覆盖 |
| Windows 待验证 | 本证据在 WSL2/Linux 产出；契约目标机为 Windows（用户机 Python 3.14），`http.server`/`ThreadingHTTPServer` 行为待 Windows 实机复验 |
| 常量待批准 | 见 §3 表 |
