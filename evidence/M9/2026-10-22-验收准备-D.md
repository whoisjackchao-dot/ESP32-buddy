## 2. 执行记录

### 2.1 manifest

```
$ python3 tools/make-manifest.py
已写入 acceptance/manifest.json：149 文件 / ≈1.37 MB
$ python3 tools/make-manifest.py --check
manifest 一致（149 文件 / ≈1.37 MB）
```

分组：`firmware` / `host` / `tests` / `docs` / `flash` / `third_party` / `evidence` / `legal`。
`--check` 忽略 `generated_at` 与 `git` 字段，只比对 `path/sha256/bytes`；
新增、消失、内容变化分别报 `+ / - / ~`，任一即退出码 1。

### 2.2 门槛预检（无设备）

```
$ python3 tools/gate-host-smoke.py
[PASS] G6-host: 20/20 HTTP 200，sink 20/20 行
[PASS] FAULT: 7/7 按预期拒绝；sink 20→20（应不变）
      延迟 ms: min 0.90 / avg 1.68 / max 11.95
```

- **G6-host**：20 个合法事件（6 类轮转）全部 200，sink 收到 20 行。
- **FAULT**：非 JSON / 顶层数组 / 错误 version / 未知 event / 错误 Content-Type / 空 body / 超长 body —— 7/7 按预期拒绝（400/415/413），**sink 未被污染**。
- 延迟仅代表主机侧（loopback），**不能**用来推断 G6 的「设备 1 s 内显示」。
