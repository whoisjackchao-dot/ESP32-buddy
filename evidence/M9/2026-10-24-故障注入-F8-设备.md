## 发现的缺陷（已修）

`pet_pomo_tick` 用**无符号**差值累计：`elapsed_ms += now_ms - since_ms`。时间回拨时 `now < since` → 差值回绕成巨大数 → **立即误判 FOCUS_DONE 并 +1 统计**。

修复：改为有符号差值，回拨/停滞不推进并重置起点：
```c
const int32_t dt = (int32_t)(now_ms - p->since_ms);
if (dt <= 0) { p->since_ms = now_ms; return; }
p->elapsed_ms += (uint32_t)dt;
```
回归：`tests/test_pet_pomo.c` `pomo14_rewind_no_false_done`（RED：5 项失败 → GREEN）。
