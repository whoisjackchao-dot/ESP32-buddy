设备侧"帧率是否掉"仍需真机（`F6` 不因 host 通过而关闭）。

### 2.3 单进程桥

```
$ python3 host/pet_bridge.py --port 8902 --serial /dev/definitely-not-a-port
bridge: http://127.0.0.1:8902/v1/events → /dev/definitely-not-a-port
$ curl -X POST ... /v1/events        → 200
bridge: 串口写入失败，重连一次：[Errno 2] could not open port ...
bridge: 丢弃一行（串口不可用）
```

**降级策略**：写失败 → 关旧句柄 → 重开一次 → 仍失败则丢弃并在 stderr 记账。
**不缓存重放**（明确不做），因此 **HTTP 200 ≠ 已送达**，G6 必须看屏幕。

新增测试 `host/tests/test_pet_bridge.py`（8 项）：分帧、惰性开串口、重连一次成功、
两次失败记账、开串口异常不崩、HTTP→串口端到端、非法请求不入串口。

```
$ ./host/run-tests.sh
Ran 77 tests in 1.073s
OK
```
