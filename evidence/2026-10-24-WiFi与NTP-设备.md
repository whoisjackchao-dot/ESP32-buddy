# WiFi AP 配网 + STA + SNTP 授时（热点网页配网，夜间熄屏拿到真实小时）

> 日期：2026-10-24　·　设备：M5StickS3（ESP32-S3，2.4 GHz）　·　修订：同日重设计——一次性 `wifi.set` 串口配网**移除**，改为**设备开热点 + 手机网页配网**
> 状态：**代码就绪，未上机验证**（本机无 ESP-IDF，无法 build/flash；Windows 侧构建）
> 关联：M8 增量 1（休闲/熄屏）· Q17=A（仅授时）· M8 §6.1 夜间窗口 23:00–07:00

## 设计（新版）

```
开机 ──读 NVS(petnet/ssid,pass)──►
   无凭据 ──────────────► 配网模式：AP 热点 + :80 配置页 + :53 DNS 劫持
   有凭据 ──► STA 连接（断线 0/10/20/30/40 s 退避重连）
                 │ 连续 5 个连接周期（≈2 min）无 IP
                 ▼
              回落配网热点（日志 net: sta failed, entering provisioning）→ 用户网页改密码
拿到 IP ──► SNTP（cn.pool.ntp.org / pool.ntp.org，TZ=CST-8）→ pet_engine_set_hour24 + 每小时重推
```

状态机在 `pet-net` 任务内（`idle/sta/ap` 三态），WiFi/HTTP/DNS 全部由任务与各自服务承载，**不阻塞显示/按键/宠物**；任何失败只记日志降级。

## 配网页端点（仅配网热点存活时可达，http://192.168.4.1）

| 端点 | 方法 | 行为 |
| --- | --- | --- |
| `/` | GET | 中文配置页（家庭 WiFi 名称 `ssid` + 密码 `password` + 保存并连接），内联样式/脚本，无外部资源；页面拉取 `/status` 显示当前状态（未配置 / 已保存，正在连接 / 已连接 IP / 时间同步） |
| `/status` | GET | JSON `{"state":"ap|sta|idle","ssid":"…","ip":"…","hour":-1}`；**绝不含口令**；hour 未同步为 -1 |
| `/save` | POST | `application/x-www-form-urlencoded`；解析 + URL 解码（`+`→空格、`%XX`）；校验 ssid 1..32 字节、pass 0..64 字节；合法：先回"已保存，正在连接家庭 WiFi，可断开热点"页，再交 `pet_net_apply_credentials()`（存 NVS → 状态机 1.5 s 宽限后停热点连 STA）；非法：**400** + 错误页。**口令绝不入日志** |

DNS 劫持：UDP :53 收到任意查询（非应答、QDCOUNT≥1）→ 回一条 A 记录 192.168.4.1（TTL 60 s），手机连上热点后自动弹配网页。

热点规格：SSID `ESP32-Buddy-XXXX`（XXXX = softAP MAC 末 2 字节大写十六进制）、开放无口令、信道 1、最多 4 连接、AP IP 192.168.4.1（显式设置）。

## 串口命令（NDJSON，USB-Serial-JTAG）

| 命令 | 效果 | 日志 |
| --- | --- | --- |
| `{"version":1,"cmd":"wifi.provision"}` | 立即进配网热点（STA 在连则先断开；凭据保留） | `net: provisioning requested` + `net: provisioning AP ssid=ESP32-Buddy-XXXX ip=192.168.4.1` |
| `{"version":1,"cmd":"wifi.status"}` | 打印状态 | `net: status state=<ap\|sta\|idle> ssid=<s> ip=<ip> hour=<h>`（无则 `-` / `-1`） |
| `{"version":1,"cmd":"wifi.clear"}` | 擦 NVS 凭据 → 断开 STA → 开配网热点 | `net: credentials cleared` + provisioning 行 |
| ~~`wifi.set`~~ | **已移除**（网页配网取代） | — |

## NVS / 凭据安全

- namespace `petnet`；键 `ssid`（≤32 字节）、`pass`（≤64 字节），`nvs_set_str` + commit。
- `esp_wifi_set_storage(WIFI_STORAGE_RAM)`：esp_wifi 默认 flash 存储不落凭据。
- 口令只在内存传递（/save → apply → wifi config），代码、日志、/status、串口均不回显。

## 边界与不变量

- 无凭据/配网/断网时，显示、宠物、按键行为与此前完全一致（net 失败只降级，不阻塞不崩）。
- 未触碰 host 侧模块（pet_state/render/link/pomo/leisure）、tests、contracts。
- 热点/HTTP/DNS 任务停止顺序：httpd_stop → DNS 任务退出（≤500 ms）→ `esp_wifi_stop`，之后才切 STA，避免半拆状态。
- 每次仅一种模式存活（AP 或 STA），由 pet-net 任务单线串行切换，无锁。
