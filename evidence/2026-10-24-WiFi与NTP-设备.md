> 日期：2026-10-24　·　设备：M5StickS3（ESP32-S3，2.4 GHz，仅 STA，无配网 UI）
> 状态：**代码就绪，未上机验证**（本机无 ESP-IDF，无法 build/flash；Windows 侧构建）
> 关联：M8 增量 1（休闲/熄屏）· Q17=A（仅授时）· M8 §6.1 夜间窗口 23:00–07:00

## 增加了什么

| 文件 | 变更 |
| --- | --- |
| `firmware/components/pet/include/pet_net.h` + `pet_net.c`（新增） | WiFi STA + SNTP：任务化、非阻塞；凭据只存 NVS；断线退避重连；每小时重算本地小时 |
| `pet_engine.c/h` | 编译期 `PET_ENGINE_HOUR24(-1)` 改为运行时 `s_hour24=-1`；新增 `pet_engine_set_hour24(int)`（钳位 -1..23）。**未注入时行为与原默认完全一致（不熄屏）** |
| `pet_rx.c` | `apply_line` 里 PET_TEST_CLOCK 块之后、事件解析之前：行内含 `"cmd"` 且 `pet_net_handle_line` 命中 → 直接返回；未识别的 cmd 照旧走事件解析被拒 |
| `main/main.c` | NVS init 之后调用 `pet_net_start()`（只建任务，不阻塞启动） |
| `components/pet/CMakeLists.txt` | SRCS 加 `pet_net.c`；PRIV_REQUIRES 加 `esp_wifi esp_netif esp_event lwip` |

实现要点：

- `pet_net_start()` 只创建 `pet-net` 任务。无凭据时打 `net: no credentials` 后**停车**（挂在任务通知上，绝不碰 WiFi），设备行为与改造前逐字节一致；收到 `wifi.set` 由任务唤醒完成"读 NVS → 连接"。⚠️ 与字面规格的差异：任务不退出而是停车等待，这样后续 `wifi.set` 无需重新 spawn。
- 断线：`WIFI_EVENT_STA_DISCONNECTED` 只置重连标志，由网络任务按 0/10/20/30/40 s 退避执行 `esp_wifi_connect()`，日志 `net: wifi retry`。
- 拿到 IP（`IP_EVENT_STA_GOT_IP`）才记 `net: wifi connected ip=<ip>`。
- SNTP 用 `esp_sntp.h` 的 `esp_sntp_*` API：`SNTP_OPMODE_POLL`，服务器 `cn.pool.ntp.org`、`pool.ntp.org`；时区 `setenv("TZ","CST-8",1); tzset();`（UTC+8）。
- 同步回调与每小时循环都调 `push_hour`：`localtime_r` 取 0..23 → `pet_engine_set_hour24(h)`，日志 `net: sntp synced hour=<h>`。WiFi 断开后保留最后一次小时值。
- 失败只记日志不崩：WiFi 初始化/启动失败、NVS 读写失败均降级为日志，主循环与 UI 不受影响。

## 命令协议（NDJSON，USB-Serial-JTAG，单行）

| 命令 | 效果 | 日志 |
| --- | --- | --- |
| `{"version":1,"cmd":"wifi.set","ssid":"…","password":"…"}` | 存 NVS → 唤醒任务（重）连接 | `net: credentials saved` |
| `{"version":1,"cmd":"wifi.status"}` | 打印 ssid / ip / 已同步小时 | `net: status ssid=<s> ip=<ip> hour=<h>`（无则 `-` / `-1`） |
| `{"version":1,"cmd":"wifi.clear"}` | 擦 NVS → 断开并停 WiFi（SNTP 同步停；小时值保留） | `net: credentials cleared` + `net: wifi cleared` |

解析用自写小扫描器（`strstr` + 引号字符串取值，容忍冒号两侧空白，支持 `\"` 转义）；ssid>32 或口令>64 拒绝并打 `net: wifi.set invalid`。**口令永不回显**。version 字段不校验（容错）。

## NVS

- namespace `petnet`；键 `ssid`（≤32 字节）、`pass`（≤64 字节），`nvs_set_str` 存储。
- WiFi 侧 `esp_wifi_set_storage(WIFI_STORAGE_RAM)`：凭据只落我们自己的命名空间，不进 esp_wifi 默认 flash 存储。
- `wifi.clear` 用 `nvs_erase_all(petnet)` + commit。
