## 2. GREEN

实现 `pet_render_skit`：整屏 `PET_SCENE_BG` → 按 §7.1 表算每剧目位移 `(ox, oy)`（`phase = t_ms % 2000`）→ 需要换帧的剧目（4 躲下时 / 5 / 6）改写 `pet_view_t` **本地副本**后调 `pet_render_pet` → 画道具。非法 id（<0 或 >6）直接委托 `pet_render_scene`（逐字节等同值班整屏）。null `s`/`look` 守卫与 `pet_render_pet` 同法。

`CC=tools/host-cc.sh bash tests/run.sh` → `test_pet_render` **94 checks, 0 failed**，退出码 **0**（全套件 **485 checks, 0 failed**，既有 10 套件 420/0 保持）。

| 用例 | 断言要点 |

| `LEI-04` 踢球 | 右下区（x 90..134, y 156..183）出现白色小球；t=0 与 t=1000 摘要不同（球沿弧线动了） |

## 3. 参数（提案值，待批准）

| 符号 | 值 | 依据 |
| --- | --- | --- |
| `SKIT_PERIOD_MS` | 2000 | 契约 §7.1（位移以 2 s 为周期） |
| 巡逻 x | `±6·cos(2π·phase/2000)` | 契约 §7.1 "x = ±6 来回（sin）"；取**余弦相位**使 t=0 在 +6、t=1000 在 −6（纯正弦两时刻同为 0，无位移对比点） |
| 踢球 y | `±3·sin(2π·phase/2000)` | 契约 §7.1 "y 弹跳 ±3" |
| 小球 | 8×8 切角圆盘（`(2dx−7)²+(2dy−7)² ≤ 52`），圆心沿 `x: 96→120`、`y: 168−24·sin(π·phase/2000)` 的弧线 | 契约 §7.1 "8×8 小球沿弧线（右下）" |
| 看书 | 头像 `oy=+2`；书 = 16×8 灰矩形 `(59,158)`+ 2 条白页线（y=160/163） | 契约 §7.1 "略低（+2）+ 16×8 矩形 + 两条书页线" |
| 数星星 | 头像 `oy=−2`；3 颗十字星光（臂 2，9 px/颗）于 (30,12)/(66,6)/(102,14)，第 i 颗在 `(phase/250+i)%2==0` 时可见 | 契约 §7.1 "上抬 −2 + 3 颗星光闪烁（交替显隐）"；交错槽位 = "交替"取读 |
| 躲猫猫 | `oy` 三角波 0→+10→0（每 100 ms 步进 1）；`oy>4` 时换 `PET_FRAME_EYES_CLOSED` | 契约 §7.1 "y 0→+10→0；躲下时闭眼"（阈值 4 为提案） |
| 被吓醒 | 前 300 ms `oy` −6→0（每 50 ms 步进 1），恒 `PET_FRAME_INPUT` | 契约 §7.1 "急跳 −6→0；睁大眼帧" |
| 梦话 | 头像静止 + 恒 `PET_FRAME_EYES_CLOSED`；`(phase/250)%2==0` 时在立绘嘴部 `look(21,41)`→屏幕 `(61..62,106)` 画 2×1 黑像素 | 契约 §7.1 "闭眼帧 + 嘴部小开合（2 帧交替）"；嘴部坐标由 `robot.look` 帧实测得出 |
| 道具颜色 | 星光 `0xFFE0` 黄 / 小球·页线 `0xFFFF` 白 / 书身 `0x8410` 灰 / 嘴部 `0x0000` 黑 | 契约 §7.1 "沿用调色板硬编码 RGB565，与头顶标记同法" |
| 非法 id | `<0 或 >6` → 委托 `pet_render_scene` | 契约 §7.1 剧目仅 0..6；任务要求 "behaves like a normal scene" |

## 4. 残余风险

| 风险 | 说明 |
| --- | --- |
| 美术为程序化示意 | 圆盘球 / 矩形书 / 十字星光均为几何示意，非逐帧美术（契约 §7.3 明确"不做小剧的复杂逐帧美术"）；2× 缩放下的观感未经真人评审 |
| 真机未目视 | 仅 host 出图 + 像素核对；ST7789 实机 gamma/视角下的黄色星光、白球对比度未验证（H 类待设备） |
| 取读待评审 | 巡逻取余弦相位（t=0 在端点 +6）、躲猫猫闭眼阈值 `oy>4`、星光交错显隐（非齐闪）、被吓醒线性回落（非保持 −6 后突变 0）均为提案取读，若评审否决只改对应 case 一处 |
| 引擎接入不在本记录 | §7.2（值班模式跑休闲、`LIGHTS_OUT` 关背光）属并行增量；本记录只覆盖 §7.1 渲染函数本身 |
| 帧选择继承 view | 剧目未覆盖的 view 字段（`mirror`/`gray`/`hair_right`/`state` 头顶标记）原样带入小剧画面；休闲态下调用方喂什么就画什么，未在渲染层清洗 |
