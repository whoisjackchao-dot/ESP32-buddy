## 2. GREEN

实现：

- `pet_link.c`：`tasks` 键 → 数组则逐项解析（对象项取 `title/project/elapsed_s/status`，类型不符的项消费后丢弃；非对象项跳过；只收前 3 个对象项）；非数组 → 该键按通用值跳过。`skip_value` 升级为可跳过对象/数组（深度帽 8，见 §3）——**任何未知键的数组/对象不再报 JSON 错**（M8 扩展点）。顶层单卡字段与错误码行为不变。
- `pet_state.c`：单卡字段改栈 `cards[3]`/`card_count`；`set_card` 升级为按 title 的入栈/更新（同名 → 更新并置顶；>3 丢底部；空 title 忽略；NULL 清栈）；新增 `pet_state_set_cards`（整栈替换）；`pet_state_view` 填 `cards[]`/`card_count`，`card`/`has_card` 取顶部卡。
- `pet_render.c`：`card_count >= 2` → 紧凑行（每行 28 px：3px 状态条 + 标题 1× ≤14 字符 + 第二行 `project · elapsed` 1× 灰 ≤14 字符，无省略号截断）；`card_count <= 1`（含旧式 `has_card`+`card_count==0` 视图）→ 原大卡，一行未动。
- `pet_rx.c`：`card_count > 0` → `pet_state_set_cards`（整栈替换）；否则回落单卡 `set_card`（M4 兼容）。

`CC=tools/host-cc.sh bash tests/run.sh` → 全部 11 套件 **589 checks, 0 failed**，退出码 **0**（基线 485 → 589，新增 104 checks：link +51、state +36、card +17）。另用 M4 §3 上游示例行（`title`+`tasks`+`stats` 同行）做了一次行外冒烟：`OK`，顶层卡 GAMMA 与 2 张任务卡并存，状态映射正确。

## 3. 参数（提案值，待批准）

| 符号/规则 | 值 | 依据 |
| --- | --- | --- |
| status 映射 | `working`→WORKING；`input_required`→INPUT_REQUIRED；`done`→DONE；`failed`→FAILED；**缺省/未知 → WORKING** | M8 §8.1（"缺省 `working`，未知值按 `working`"） |
| **替换 vs 合并** | 每条消息的 `cards[]` **整体替换**栈内容（top-first 原样、≤3 截断、空 title 项跳过；`count<=0` 不动栈）——收件侧 `card_count>0` 时走替换，顶层单卡键只在无 tasks 时生效 | 任务指定取最简一致规则；M8 §8.2 只定义了 `set_card` 的入栈/更新，消息级替换语义为本实现选定并在此登记 |
| 栈容量 / 版式 | 栈 3 张；紧凑行 `x=4..131`、`y=150` 起、每行 28 px、状态条 3 px（沿用 `state_accent`）、文本 `≤14` 字符、标题 y+3 / 次行 y+15 | M8 §8.4 提案值 |
| `SKIP_MAX_DEPTH` | 8（`skip_value` 递归跳过的嵌套深度帽） | 行输入不可信且 `pet_rx` 任务栈仅 4 KB（M4 §4.7 不崩）；512 B 行最多 ~250 层嵌套，不设帽可爆栈。host 栈大、测试无法区分有无帽，故只有"深度 5 仍可跳过"的回归锁，帽本身**未经 RED 验证** |
| 次行分隔符 | `·`（U+00B7，按契约原文）；font8x8 仅 ASCII，`pet_text_draw` 跳过该字节（渲染为空隙） | M8 §8.4 原文 `project · elapsed`；字库限制既有行为 |

## 4. 残余风险

| 风险 | 说明 |
| --- | --- |
| 版式未上屏 | 紧凑行只在 host 像素断言（y 带内容/不越界/guard），未在真机核对可读性（字号、颜色、与立绘的视觉关系） |
| 3 卡占 84~85 px | 行区 y=150..234（契约记 84 px，含端点 85 px），与立绘底部（y≤151）在 y=150..151 有 2 px 交叠，是否被立绘透明像素遮蔽未实机确认 |
| `pet_view_t` 变大 | +3×`pet_card_t`+int（约 0.5 KB）；`pet_engine`/`pet_render_skit` 的栈上视图副本随之变大，FreeRTOS 任务栈水位未测 |
| `pet_rx` 接线无 host 测试 | 替换路径的设备侧接线（USB-CDC → 解析 → `set_cards`）属固件代码，host 套件覆盖不到，需实机事件流验证（H 类） |
| 深度帽未 RED | 见 §3：`SKIP_MAX_DEPTH` 防的是设备栈溢出，host 无法构造失败先例，属加固参数而非被测行为 |
| 常量待批准 | 版式常数与替换语义若被评审否决，改 `pet_render.c` 宏区/`pet_state_set_cards` 一处即可，测试同步调整 |
