## 2. GREEN

实现 `pet_render_ring`（bbox 扫描 + `atan2` 顺时针角 + 千分比填充）、`pet_render_pomo`（底色 + 环 + 中心 `M:SS`）、统计编解码（16 字节小端，显式移位）。

`CC=/tmp/opencode/zb/cc.sh bash tests/run.sh` → **324 checks, 0 failed**，退出码 **0**（`test_pet_render` 52/0、`test_pet_pomo` 96/0，既有 5 套件 213/0 保持）。

| 用例 | 断言要点 |
| --- | --- |
| `POMO-05` | 进度 0 → 3 点（90°）为轨道色；250‰ → 90° 边界含入（90×1000 ≤ 250×360）为进度色、270° 仍轨道；1000‰ → 3/6/9 点全进度色；12 点（0°=起点，恒在带上）为进度色；洞内两点（环心、`dx=-T`）保持哨兵未被污染 |
| `POMO-05`（视图合成） | `pet_render_pomo`：NULL 视图 → 整屏仅 `PET_SCENE_BG`；FOCUS 满剩余 → 3 点轨道色 + 12 点橙 + 中心出现白色 `M:SS` 字；BREAK 剩余 0 → 3/9 点全绿（1000‰） |
| `POMO-13` | encode → 恰 16 字节：magic `PMC1`、`day=-2` 逐字节 `FE FF FF FF`、`done=3`、`focus_seconds=4500=0x1194` 小端 |
| `POMO-13` | roundtrip：encode→decode 还原 day/done_count/focus_seconds 且置 `has_day`；phase/elapsed/since/total/alarm 五字段不动 |
| `POMO-13` | 坏 magic → false 且哨兵结构 9 字段原样；坏长度（len=8）→ false 且不动 |
| `POMO-13` | `cap=8` → encode 返 0 且 buf 未被写 |

过程修正：无（首轮 GREEN 即全绿；90° 边界曾担心浮点舍入，实测 `atan2(±r, 0)*180/PI` 恰为 90.0/270.0，边界含入确定）。

## 4. 残余风险

| 风险 | 说明 |
| --- | --- |
| 圆环未实机目检 | 全部证据为 host 像素断言（64×64 合成画布 + 135×240 画布）；真机 135×240 屏上的观感/锯齿/占屏比未验证（H 类待设备） |

| 浮点角含入 | 90°/270° 基准点实测恰整，非基准像素的边界归属随 libm 实现可能有 ±1 像素差（视觉无感；若未来换工具链，`POMO-05` 基准断言会立即暴露） |
| `int32` 回转平台假设 | decode 的 `(int32_t)` 回转与 encode 的 `(uint32_t)` 取模按补码实现（clang/GCC/ESP-IDF 均满足）；C 标准层面属实现定义 |
| 口径说明（§7 歧义取读） | ① §1/7.5 提"刻度/指针重新设计"但 §7.5 又"不做刻度/指针"，按**纯填充环**实现；② 进度 0 时 12 点起点像素按公式属进度色（0≤0），系规格字面结果；③ decode 成功只动统计四件套，取 §7.3"不改 `p`"最窄读法；④ `pet_render_pomo` 另加 3 条最小合成断言（NULL→底色、FOCUS、BREAK）以满足"无失败测试不写实现"，未改任何既有断言 |
