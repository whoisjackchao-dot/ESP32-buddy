## 4. 残余风险

| 风险 | 说明 |
| --- | --- |
| **窗口激活未在 Windows 实测** | `win_focus` 仅经类型检查与 Linux 守卫路径（非 win32 → `False`）；`AttachThreadInput` + `SetForegroundWindow` 方案受 Windows 前台锁策略影响，真机效果未验证（H 类待设备） |
| **无鉴权** | 守护进程对 COM5 来者不拒（§8.3 明确：仅本机 USB loopback，无鉴权）；任何能写该串口的进程都能触发窗口切换 |
| **目标窗口启发式** | 类名 + `OC` 前缀是**约定**而非保证：若用户改终端或标题前缀，定位失败（静默返回 `False`）；`B08` 本就不承诺任意窗口定位（§8.4） |
| `--baud` 仅 CLI 生效 | `run()` 无 baud 形参（按任务签名冻结）；CLI 路径由 `main` 打开串口再注入 `run`，直接调 `run(port=...)` 固定 115200 |
