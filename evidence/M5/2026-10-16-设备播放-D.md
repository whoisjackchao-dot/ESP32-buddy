## 4. 复用的既有结论（**非本项目实测**）

`pet_audio.c` 的参数与流程照抄同作者既有 StickS3 项目（MIT）中已在实机验证的实现：

| 项 | 值 | 来源 |
| --- | --- | --- |
| 采样 | 16 kHz / 16-bit / **STEREO 槽位** | 其 `audio_capture.c` + 硬件知识文档 §附录B（MONO 会使 WS=32k → 2 倍拉伸） |
| MCLK 倍数 | **256** | 同上（其值曾疑为 384，未定案；沿用 256） |
| I2S | `I2S_NUM_0` master，DMA 6×240 | 同上 |
| 引脚 | MCLK18 / BCLK17 / WS15 / DOUT14 | 其硬件文档 §4.2 |
| 功放 | `pm1_es8311(true/false)` 包住播放 | 其 `audio_capture_beep` |

## 5. 明确未做 / 残余风险

| 项 | 说明 |
| --- | --- |
| **H 类未做** | 未刷机；**没听到声音**；音量/是否爆音/是否 2 倍拉伸**均未验证** |
| MCLK 倍数含疑 | 其注释自述 256/384 未定案；语音对速率误差比提示音敏感，**实机需重点听** |
| 与麦克风共存 | 本项目不做采音；其项目曾因 I2S 共用/时钟问题踩坑，未验证 |
| 资源占用 | app 余 53%；若后续加角色立绘/多语音需复核分区 |
| 静音/播报时机 | 逻辑已测（M5 增量 1），**实机行为未验** |
