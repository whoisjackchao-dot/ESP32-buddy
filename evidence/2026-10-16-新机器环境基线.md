## 2. 处置：用**用户态** C 工具链绕过（无需 sudo）

系统无编译器且无免密 sudo → 无法 `apt install build-essential`（即 `B13` 在原机器的解法在本机不适用）。
改用**用户态 zig**（自带基于 LLVM/Clang 的 C 编译器 `zig cc`），全过程不需要 root：

```bash
mkdir -p /tmp/opencode/zb && cd /tmp/opencode/zb
# 取 ziglang.org 官方索引，下载 linux-x86_64 tar.xz（~49 MB）并解压
ZIG=$(ls -d /tmp/opencode/zb/zig-*/ | head -1)
"$ZIG/zig" version          # → 0.14.1
printf '#!/usr/bin/env bash\nexec %s/zig cc "$@"\n' "$ZIG" > /tmp/opencode/zb/cc.sh
chmod +x /tmp/opencode/zb/cc.sh
```

> **不承诺长期可用**：本工具链落在 `/tmp`（易失），且 `zig cc` 的告警集与系统 gcc 未必逐条一致。
> 若要长期用，应放到持久的用户目录（如 `~/.local/zig`）并在 `tools/` 里记一笔。
