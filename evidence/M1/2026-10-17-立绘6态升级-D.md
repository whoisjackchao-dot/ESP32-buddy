# M1 · 立绘 6 态升级（4→6 帧，毛绒吉祥物风格）· D 类记录

> 日期：2026-10-17　类别：**D**（资产/构建）
> 结论范围：**资产重生成 + 固件接线 + host 全绿**。**未刷机、未在设备上目视** → 不构成 H 类验收。

## 1. 变更内容

| 项 | 原 | 现 |
| --- | --- | --- |
| 立绘帧数 | 4 `[NORMAL, EYES_CLOSED, HAPPY, SAD]` | **6**：追加 `PET_FRAME_WORKING=4`、`PET_FRAME_INPUT=5`（0–3 编号不变，`PET_FRAME_COUNT=6`） |
| LOOK 包 | 6184 B | **9256 B**（40 头 + 6×1536 帧）；格式不变，仅 frames 字节 4→6；`pet_look_parse` 校验规则不变 |
| 状态→帧 | WORKING/INPUT 用 NORMAL+头顶标记 | WORKING→4（伏案笔记本）、INPUT_REQUIRED→5（举爪+气泡）；IDLE/DONE/FAILED/OFFLINE 映射不变，idle 眨眼/小动作逻辑原样保留 |
| 风格 | 蓝色机器人头（硬边） | **奶油色毛绒吉祥物**：圆耳、圆润大头、大眼+高光、腮红、肚皮；一态一姿（见下） |

六帧姿态：0 端坐微笑 / 1 闭眼安睡 / 2 弹跳欢呼+星光 / 3 八字眉+汗滴+波浪嘴 / 4 低头伏案敲小笔记本 / 5 举右爪+左上 "!" 气泡。

## 2. 原创声明

- 风格**方向**受 Meta Muse 吉祥物（kawaii/毛绒/圆头）启发；所有形状、配色、姿态、像素均由 `tools/make-look.py` 程序化自绘，**净室**，未复制 Meta/Jolly 任何素材、数据文件或具体造型，未引入任何外部资产。
- LOOK 二进制格式沿用上游规格（magic/头/调色板布局），仅帧数字段变化。

## 6. 明确未做 / 残余风险

| 项 | 说明 |
| --- | --- |
| 程序化像素画的上限 | 48×64 程序化椭圆拼形，细节（如嘴形、爪形）不如手绘/AI 出图精致；已按"小尺寸第一读"取舍 |
| 真机目视待刷机 | 96×128 实屏观感、灰化效果、与任务卡同屏构图未上机验证 |
| OFFLINE 无帧内 "Z z" | OFFLINE 与 idle 眨眼/打盹共用帧 1；帧内画 Zz 会在 1 Hz 眨眼时闪烁，故靠闭眼睡姿+灰化表达（专属睡姿需第 7 帧，超出本次冻结，见契约 M1 §10） |
| 交叉编译未跑 | 本机无 ESP-IDF 环境；`LOOK_FRAMES` 为编译期常量，`pet_look_t` 变大 3 KB（栈/堆占用在 heap 8.5 MB 上可忽略），风险低但未实测 |
| 旧证据中的 6184 | `evidence/M1/2026-10-16-固件构建-D.md`、`evidence/2026-10-17-实机刷机-H.md` 中的 6184 B 为当时事实，不改历史；下次构建按 9256 核对 |
