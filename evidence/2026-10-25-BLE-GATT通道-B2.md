# B2：BLE GATT 通道（RX 写事件 / TX notify 控制行）

- 日期：2026-10-25 / PC：Windows WinRT（Python 3.12 winrt）
- 服务：`0xFFE0`；RX `0xFFE1`（write / write-no-rsp，主机→设备事件行）；TX `0xFFE2`（notify，设备→主机控制行）
- 行格式与 USB/WiFi 完全一致：事件 `{"version":1,...}`（设备解析键为 `version`，不是 `v`）；控制行 `{"v":1,"cmd":...}`

## 验证（全部真机）
| 项 | 结果 |
| --- | --- |
| GATT 服务发现 | ✅ `services=3`（0x1800 / 0x1801 / **0xFFE0**），chr 0xFFE1/0xFFE2 |
| RX（PC→设备） | ✅ 写 `{"version":1,"event":"task.start","title":"RXOK",...}` → 设备 `rf st=1 n=1 top=RXOK`（工作态 + 卡片） |
| TX（设备→PC） | ✅ 菜单 BACK: WINDOW → PC 收到 `NOTIFY: {"v":1,"cmd":"back_window"}` |
| 连接 | ✅ 未配对直连（`conn=1`）；断开后自动重新广播 |

## 踩坑与修复
1. **显式调用 `ble_gatts_start()` 导致 GATT 服务未注册**（服务发现 0 个）→ 移除，交给 host start 自动调用；已加 `gatt count=%d add=%d` 日志。
2. 刷机重启丢绑定（NVS 未持久化）→ 已开 `CONFIG_BT_NIMBLE_NVS_PERSIST=y`。
3. Windows 陈旧配对记录导致 GATT Unreachable → 设置里删除旧条目后重连正常。
