## 3. 设计

### 3.1 进程树与数据流

```
tools/esp32-buddy-up.sh
  └─ nohup python3 host/pet_supervisor.py --log /tmp/esp32-buddy.log --state /tmp/esp32-buddy.state
       ├─ slot 0: python3 host/oc_poll.py --out /mnt/d/buddy_flash/oc_events.log   （WSL 侧）
       └─ slot 1: powershell.exe -NoProfile -Command
                  "& '<win python>' '<host>\file_to_serial.py' --log 'D:\buddy_flash\oc_events.log' --port COM5"
```

NDJSON 语义不变（M4 §6.1）：`FileSink` 复用 `pet_transport.ensure_line`（compact、
ensure_ascii=False、单行尾 `\n`），每行即写即 flush；桥只透传字节，不改内容。

### 3.2 backoff

- 每槽独立：退出后等 `delay` 再拉起，`delay = min(delay*2, 30s)`，初值 1s。
- 稳定复位：运行时长 ≥ 30s（cap）后崩溃的子进程，下次只等基础步长——避免长期运行后
  一次崩溃被永久惩罚。
- 实测（smoke，fake child `sleep 0.4`）：`restart in 1.00s` → `restart in 2.00s`，日志逐行带时间戳。

### 3.3 pidfile / state / 日志

| 文件 | 内容 | 谁写 |
| --- | --- | --- |
| `/tmp/esp32-buddy.pid` | supervisor pid | up 写、down 删 |
| `/tmp/esp32-buddy.state` | JSON：每槽 argv/pid/state/restarts/delay | supervisor 每次启动/退出/停止原子重写（tmp+rename） |
| `/tmp/esp32-buddy.log` | start/exit/stop 行，`%Y-%m-%dT%H:%M:%S` 前缀 | supervisor 追加 |

全部可用 `BUDDY_PIDFILE` / `BUDDY_LOG` / `BUDDY_STATE` 环境变量改写（测试即依赖此点：
pidfile 指向临时目录，"存活 pid" 用测试进程自身或测试自建的 `sleep` fake child，绝不 kill 真实进程）。

### 3.4 `--check`（WSL 可用）

只 stat 路径、不启动任何子进程：oc_poll.py / file_to_serial.py / win python（原始路径与
`win_to_wsl` 换算路径任一存在即可）/ OpenCode db / out 目录。全 OK → exit 0，否则 1。
win python 可用 `--win-python` 或 `BUDDY_WIN_PYTHON` 覆盖（默认
`D:\Espressif\python_env\idf5.5_py3.14_env\Scripts\python.exe`）。

## 4. 用法

```
bash tools/esp32-buddy-up.sh       # 幂等启动：已在运行则 "already running" 且 exit 0
bash tools/esp32-buddy-status.sh   # pid 存活 + 子进程状态 JSON + 日志尾 5 行（exit 0=运行中）
bash tools/esp32-buddy-down.sh     # TERM supervisor（它会 TERM 自己的子进程），幂等
python3 host/pet_supervisor.py --check
```

`/esp32-buddy` 项目命令（`.opencode/command/esp32-buddy.md`）：agent 依次跑 up → status
并汇报结果；明确禁止 down / kill / 改日志，发现反复重启或缺项时只如实上报。

## 5. 本机实测（非测试路径）

- `--check` 本机 → 5 项全 OK，rc=0（本机 /mnt/d 已挂载、db 在）。
- supervisor 真实 run-loop（`--children '[["sleep","0.4"]]'`，3 s）：日志
  start/exit/backoff 1.00s→2.00s、TERM 后 `supervisor stop`、state 收敛为 `stopped`。
- 脚本默认路径 smoke：无 pidfile 时 status rc=1 `not running`、down rc=0 幂等。
- `command -v powershell.exe` → `/mnt/c/Windows/System32/WindowsPowerShell/v1.0/powershell.exe`。
